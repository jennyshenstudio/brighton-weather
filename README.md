# Brighton Weather

A bootcamp exercise: show the current weather in Brighton using the free [Open-Meteo](https://open-meteo.com/) API. Plain HTML and JavaScript, no libraries, no API key.

Open any file in a browser by double-clicking it.

| File | Stage |
| :-- | :-- |
| `stage1-setup.html` | Settings and the forecast URL |
| `stage2-fetch.html` | Fetch the data and show the raw JSON |
| `stage3-parse.html` | Pick out the weather, with error handling |
| `stage4-refresh.html` | Refresh button and readable formatting |
| `stage5-apple-design.html` | Stage 4 restyled to follow Apple's Human Interface Guidelines |

Weather data by [Open-Meteo.com](https://open-meteo.com/).
